# Pousada Passárgada — Public Project Showcase

> Public documentation of professional and digital-product work. The implementation repository and operational data remain private.

## Overview

This case represents work carried out in a real hospitality operation, combining reception, reservations, guest experience, commercial communication, marketing analysis and digital-product development.

The website is one part of the work, not the whole role.

## What this showcase demonstrates

- Information architecture for a hospitality website.
- Reservation journey connected to an external booking engine.
- Clear boundary between website responsibilities and OmniBees responsibilities.
- SEO migration strategy with redirects, canonical URLs, sitemap and robots.
- Campaign attribution using UTMs.
- Consent-aware analytics with GA4/GTM.
- Technical handoff and migration planning.
- Product decisions grounded in real guest and reservation workflows.

## Main digital flow

```text
Campaign → Landing page → Reservation CTA → OmniBees → Conversion → Measurement
```
